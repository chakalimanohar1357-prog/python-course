# Python Course

My Python learning journey, organised day by day.

| Day | Topics | Files |
|-----|--------|-------|
| Day 1 | Basics, input/output, operators (arithmetic, assignment, relational, logical, bitwise, shifts) | `firsts.py`, `arithmetic.py`, `assignment.py`, `relational.py`, `logical.py`, `bitwise_operator.py`, `leftshift.py` |
| Day 2 | Simple programs (areas, interest, temperature, swap), conditional statements | `areas.py`, `problems_basic.py`, `conditional_stm.py`, `watermelon_pron.py` |
| Day 3 | Loops, break/continue, star & number patterns | `loops.py`, `patterns.py`, `patterns2.py` |
| Day 4 | Number problems (perfect square, Armstrong, ...), number system conversions | `problems_numbers.py`, `conversions.py` |
| Day 5 | Strings: indexing, slicing, operations, string problems | `strings.py`, `problems_strings.py` |
| Day 6 | Functions, return values, lambda functions, function-based problems | `functions.py`, `lamda_function.py`, `problems_functions.py` |
| Day 7 | Lists and list problems (index sums, rotations, move zeroes, two sum) | `lists.py`, `problems_lists.py` |
| Day 8 | Sets and tuples | `set.py`, `problems_sets.py`, `tuple.py`, `problems_tuples.py` |
| Day 9 | Dictionaries and dictionary problems | `dictionaries.py`, `dic_problems.py` |
| Day 10 | Two pointers, sliding window, searching, sorting | `two_pointers.py`, `searching.py`, `sorting.py` |
| Day 11 | Singly linked list and linked list problems | `linked_list.py`, `linkedlist_problems.py`, `total_linked_list.py`, `linkedlist_extra.py` |
| Day 12 | Circular linked list | `circular_linked_list.py`, `total_circular_linked_list_extra.py` |
| Day 13 | Doubly linked list | `double_linked_list.py`, `dll_insertion_deletion.py`, `total_double_linked_list.py`, `dll_problems_extra.py` |
| Day 14 | Recursion, stack (list/linked list, min stack, two queues, sort, postfix, next greater) and queue (deque, linked list, circular, priority queue, sliding window max) | `recursion.py`, `recursion_extra.py`, `stack_extra.py`, `queue_extra.py` |
| Day 15 | Trees: traversals, BST search/insert/delete | `trees.py`, `bst.py`, `total_trees_code.py`, `trees_extra.py` |
| Day 16 | Graphs: adjacency list, BFS, DFS | `graphs.py`, `graphs_extra.py` |

## Run
```bash
python Day1/firsts.py
```
Many programs are commented out; uncomment the one you want to run.

Files ending in `_extra.py` hold extra practice topics added to fill gaps in the course.
